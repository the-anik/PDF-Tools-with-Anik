Conversions

Convert to and from PDF

Export PDF pages as image files, combine images into PDF, or turn plain text into a clean paginated PDF.

Conversion settings

About conversions

PDF-to-image output is rendered from the visible PDF pages. Each output image uses a page-based filename; multiple images are downloaded as a ZIP. With the size limiter on, every image is tuned to fit under your limit (PNG falls back to JPG if needed).
Image-to-PDF preserves image proportions in Contain mode. Fill mode may crop image edges by design. The size limiter caps the total size of the PDF.
PDF-to-DOCX / DOCX-to-PDF is not included because accurate document-layout conversion is not provided by the bundled browser libraries.

Batch safeguards

Files are processed one at a time to keep memory use more predictable. If one file fails, other queued files continue.
Offline OCR is not included. Batch compression uses Smart mode and keeps the original size when a file cannot be made smaller.

How compression works

▣
SmartFinds every JPEG / lossless image inside the PDF, scales it down and re-encodes it. Text and vector art stay untouched. Charts with flat colours are left alone.
▤
RasterizeBest for scans or very complex artwork. Pages become pictures, so text is no longer selectable or searchable.
≡
LosslessCompresses uncompressed streams and packs the file structure. No visual change.
The result is only offered when it is genuinely smaller; otherwise your original size is kept and you're told why.
Password-protected PDFs can't be processed. Heavily text-based PDFs rarely shrink much — Lossless or Rasterize are the only options for those.
Privacy

Redact sensitive text

Find words, emails, phone numbers and long ID numbers, review each match, and permanently black them out. Affected pages are flattened to images, so the hidden text is truly gone.

Find & redact

Read this first

What happens: every page containing a confirmed match is rendered to an image with black boxes burned in, then rebuilt as a PDF. No text, no hidden layer.
Always verify: open the output and try searching for the redacted text. Matching reads the PDF's text layer, so scanned pages without text need OCR first. Redacted pages lose selectable text; untouched pages keep theirs. Bookmarks are not carried over.

Good to know

Images are exported at their embedded resolution, not as they appear on the page. Transparency masks are not applied.
Unusual encodings (JPEG 2000, CCITT, indexed palettes) are counted but skipped. Vector drawings are not images and aren't extracted.

About PDF Tools with Anik

A focused PDF workspace with local-first processing, practical annotation and page management, and clear technical limits.

Batch operationsSequential batch rotation, watermark, page numbering and text extraction with partial-failure reporting.

Known limitations

Existing-text editing: Added text is an overlay, not native editing of original PDF text objects.
OCR / scanned PDFs: OCR engine and language files are not included in this release. Text extraction only reads existing searchable text.
Compression: Smart mode recompresses JPEG and lossless RGB/grayscale images. Indexed, CMYK, JPEG 2000 and masked images are left alone. Text-only PDFs shrink little unless rasterized.
Security operations: No cryptographic digital signatures or password removal. Redaction flattens affected pages to images.
